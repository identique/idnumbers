class documentation

class IdMetadata(SimpleNamespace):

View In Hierarchy

The description of one ID class.

It is a types.SimpleNamespace with annotated fields, built from keyword arguments such as IdMetadata(**{'iso3166_alpha2': 'TW', ...}). isinstance(metadata, SimpleNamespace) stays true.

Class Variable alias_of The class this class is an alias of, or None if it is not an alias.
Class Variable checksum Whether the design of the ID has a check digit or check letter. If it is true, the class has a checksum function.
Class Variable checksum_algorithm A short description of the algorithm that checksum computes, such as 'Luhn (mod 10)'. It is None when checksum is false.
Class Variable country_name The English name of the issuing country, the same as in the country registry, such as 'Taiwan'.
Class Variable deprecated Whether the country has replaced the ID with a newer format.
Class Variable display_format A human-readable layout of the ID, such as '###-##-####' or 'YYMMDD-SSSC'.
Class Variable example A synthetic ID that the class validates. It is constructed with a valid check digit and is not the number of any real person.
Class Variable id_type The English name of the kind of ID, such as 'National Identification Card'.
Class Variable iso3166_alpha2 The ISO 3166-1 alpha-2 code of the issuing country, such as 'TW'.
Class Variable links The reference links of the ID, such as the official page or the description of the algorithm.
Class Variable masks The layouts the class accepts, the preferred display layout first. # is a digit, L a letter, X a letter or a digit and * any non-space character. Every other character is a separator, one of ' -./()'.
Class Variable max_length The maximum length of the ID in its compact form, that is without separators.
Class Variable min_length The minimum length of the ID in its compact form, that is without separators.
Class Variable names The names and abbreviations under which the ID is known.
Class Variable official_name The official name of the ID in the local language, such as '國民身分證統一編號'. It is None when the ID has no local-language name, as with an ID that is named in English.
Class Variable parsable Whether information can be parsed from the ID. If it is true, the class has a parse function.
Class Variable regexp The compiled pattern that describes the whole ID.
